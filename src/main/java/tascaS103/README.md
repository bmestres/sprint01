# Assignment S103

## Level 1

### Exercise 1 - Duplicates
This program creates an initial ArrayList adding all months of a year except august and shows them on screen.
Then adds august at its correct position and shows new result. Finally, it traverses the collection with an enhanced for loop and
an Iterator.

### Exercise 2 - ListIterator
Creates a list of integers, copies them into another list using a for loop in reverse and
* finally adds one list to the other using a ListIterator

### Exercise 3 - Capital Game
Quiz game to guess capital cities of countries. Fetches a set of countries and their correspondent capital cities from a text file,
then runs the quiz game up to 10 rounds and stores the score along with the player's game in another text file.

**Functionalities**:
- **I/O:** Interactive menu and q&a. Prevents wrong format inputs by the user.
- **Game service:** Applies game logic and accumulates player's score.
- **Read/write data:** Allows reading and storing data from source and destination files.

**Technologies**:
**Backend** Java
